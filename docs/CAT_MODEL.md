# 剧场黑猫的正式模型方案

舞台右侧栏台现在放着一块黑猫剪影，金色双眼用于检验逆光下的可读性。场景为 `scenes/cat_placeholder.tscn`。正式模型用同一个 `TheatreSet.cat_scene` 属性接入，脚掌落在 `CatAnchor` 的本地地面，头朝画面左侧。占位件宽约 1.3 个局部单位，耳尖高约 0.72，尾巴可以垂到栏台外缘。

## 推荐制作路线

1. **先定姿势。** 选取侧面、正面和四分之三视角的同一只短毛猫参考，标出肩胛、脊线、髋部、四爪和尾根。先在菜单机位验证伏卧姿势、耳朵轮廓，以及尾巴搭过栏杆时的弧线。
2. **从可商用的猫科四足基础网格制作。** 优先选择已有四足骨架、趾行后腿和独立眼球的模型，确认许可允许随游戏分发。用 Blender 调整体态和头身比例，重新绘制黑色短毛、鼻镜、耳内和虹膜。若继续用 Meshy，可用多视图草模核对体积，再将外形转移到基础网格并人工修正肩胛和腿根。
3. **专门做菜单镜头需要的动作。** 制作一个约六秒的呼吸循环，眨眼使用形态键，耳朵和尾巴使用骨骼。呼吸时前爪保持着地，尾巴靠近栏杆的接触点保持稳定。先用短毛法线、粗糙度和轮廓光表现毛皮，仅在耳缘和颊边需要时补少量透明毛片。
4. **回到原机位验收。** 导出带骨架和待机动画的 GLB，包装成 `PackedScene` 并替换场景属性。在 1280×720 主菜单中检查双眼是否可辨、背线是否从幕布中分离，并查看最大视差与完整待机循环时的爪部滑动和尾巴穿模。
